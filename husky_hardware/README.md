# husky_hardware

## 1) Overview

`husky_hardware` provides the live `ros2_control` hardware plugin for the Husky mobile base.

It specializes the generic `4WD` hardware abstraction from `romea_mobile_base_hardware` and connects it to the Husky low-level controller through the Clearpath Horizon legacy interface.

The exported plugin is:

| Plugin | Base class | Mobile base architecture |
|---|---|---|
| `husky_hardware/HuskyHardware` | `HardwareSystemInterface<HardwareInterface4WD>` | `4WD` |

## 2) Hardware concept

`HuskyHardware` is loaded by `controller_manager` from the `<ros2_control>` description generated by `husky_description`.

At runtime, it:

1. reads the Husky `ros2_control` hardware information;
2. creates the `HardwareInterface4WD` command and state interface mapping;
3. loads front and rear wheel radii used to convert wheel angular speeds;
4. connects to the Husky low-level controller through the Horizon legacy serial interface;
5. configures low-level speed and acceleration limits;
6. converts four controller-side wheel speed commands into left and right linear speed commands;
7. sends skid-steering speed commands to the robot;
8. reads left and right differential speed feedback;
9. exposes the feedback as four wheel angular speed state interfaces;
10. sends a null command when the interface is connected or disconnected.

From the controller point of view, this behaves like a standard mobile base hardware plugin: `romea_mobile_base_controllers/MobileBaseController4WD` writes four wheel speed commands and reads wheel speed feedback from state interfaces to compute odometry.

## 3) Serial communication

The current implementation uses the Horizon legacy interface on:

```text
/dev/prolific
```

The hardware plugin sends:

* left and right linear speed commands;
* low-level speed and acceleration limits;
* null commands when the interface is connected or disconnected.

It receives:

* left differential speed feedback;
* right differential speed feedback.

The differential speed feedback is expanded into the four `ros2_control` wheel state interfaces using the configured wheel radii.

## 4) Relation with other packages

`husky_hardware` is the live hardware specialization of the Husky mobile base:

* `husky_description` selects `husky_hardware/HuskyHardware` in `live` mode;
* `romea_mobile_base_hardware` provides the reusable `4WD` hardware abstraction;
* `romea_mobile_base_utils` provides helpers used to read `hardware_interface::HardwareInfo`;
* `romea_mobile_base_controllers` sends commands through the exported `ros2_control` interfaces;
* `husky_bringup` starts the controller manager and loads this hardware plugin in live mode.
